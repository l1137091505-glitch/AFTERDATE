# AFTERDATE

AFTERDATE is an original BOT Chain fair-exchange interface for encrypted deliveries. Sellers commit to a payload hash and key hash; buyers lock exact payment; a matching key releases proceeds, while a missed deadline enables a refund.

## Included

- Original React/Vite interface with responsive editorial layout
- Wallet connection with BOT Chain network switching
- Solidity escrow contract with pull-payment withdrawals
- Preview records when no contract address is configured
- Vercel SPA configuration

## Quick start

```bash
cd frontend
npm install
npm run dev
```

The project is educational software and has not been professionally audited. Test with small amounts first.
